# Regla de Calidad Absoluta (Lean Startup / Cero Mediocridad)

**CRÍTICO - SIEMPRE DEBES RECORDAR ESTO AL TRABAJAR EN ESTE PROYECTO:**

1. **Investigación Exhaustiva:** Este sistema SCADA/IoT no es un juguete, debe ser un producto totalmente profesional. Toda la data agronómica (tiempos, fases, temperaturas, VPD, iluminación, sustrato) debe ser investigada especie por especie con rigor científico. NUNCA asumas valores ni copies y pegues datos genéricos para llenar vacíos.
2. **Cero Mediocridad:** No estamos construyendo un producto común y corriente. Si el trabajo requiere 15 búsquedas de investigación en paralelo, hazlas. La calidad no es negociable ni está sujeta a restricciones de tiempo.
3. **Sin atajos en datos:** Si una base de datos o enciclopedia tiene 20 entradas, las 20 deben ser investigadas de forma individual y llenadas con parámetros óptimos y reales según literatura verificable.
